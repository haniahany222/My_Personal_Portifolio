# My Portfolio Website
This is my personal portfolio as a front-end web developer. I'm a Software Engineering student at the Faculty of Computer and Information Sciences, Mansoura University, and I built this site to show my work in a way that's friendly and a little fun, without getting in the way of someone who just wants to see what I can do.

## What the site is about?
The site is a single page with four parts:

1. **Welcome section.** The first thing a visitor sees: my photo, a short intro, my education, and a line that keeps typing out different job titles. There are two buttons, one that jumps to my work and one that jumps to the contact section.
2. **My Work.** Cards for each project I've built. Clicking a card opens that project's own page.
3. **Toolbox.** The tools and skills I work with, shown as colorful tags.
4. **Contact.** Email, GitHub and LinkedIn links.

There's also a light/dark theme button in the navigation bar. By default the site follows the visitor's system setting.

## The project pages
Each project opens in its own themed "room". The page expands from the card you clicked, the background changes to match the project, small icons float up the screen, and the project's screen recording plays in a frame that fits the theme.

## Built with
- React 18
- Vite
- Plain CSS. The animations are CSS transitions and keyframes, including the circular reveal, the morphing photo shape and the floating icons.

The site also respects the "reduce motion" setting for visitors who prefer less animation, and it works on phones and desktops.
